Quick Setup Guide

How to configure LeetPush Chrome Extension

1

Load Extension in Chrome

Open chrome://extensions, enable Developer Mode, and click Load unpacked. Select the LeetPush/extension directory.

2

Configure Repository & Token

Open server/.env and provide your GitHub Personal Access Token, Owner, and Repo (e.g., RIKKY-J/LeetPush).

3

Solve on LeetCode

Visit any problem on LeetCode. Submit your code. Upon Accepted, LeetPush immediately pushes your solution to GitHub!
